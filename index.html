FAQ

How do I edit the files?

This is an editable SVG pack. Install the included fonts, then open a file from the feed or stories SVG folders in a desktop SVG editor with proper Malayalam shaping, such as Inkscape. Change the shop name, words, colours and hours. Keep whole Malayalam words together. Set any new Malayalam text to Manjari or Noto Sans Malayalam, not the English font.

PDF text stays selectable and the artwork stays as vectors, but how well you can edit a PDF depends on your app. Use the SVG when you need to change a headline. PNG files are flat pictures, ready to post or to drag into Canva as a background. The Malayalam on a PNG cannot be edited as individual text.

Is this a Canva template?

No. This is an editable SVG pack, not a Canva template link. Canva text-editability has not been verified, so it is not sold as an editable Canva product. Adding a PNG to Canva does not make the words editable.
